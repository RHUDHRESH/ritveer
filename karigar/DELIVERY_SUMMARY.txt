================================================================================
                         HOW TO GET STARTED
================================================================================

INSTALLATION (5 minutes):

1. Navigate to project:
   cd C:\Users\hp\OneDrive\Desktop\ArtisanHub\karigar

2. Install dependencies:
   pip install -r requirements.txt

3. Setup environment:
   cp .env.template .env
   (Edit .env with your API keys)

4. Initialize database:
   python -c "from src.karigar.schemas.models import init_db; init_db()"

5. Start API server:
   python -m uvicorn src.karigar.api.main:app --reload

6. Visit documentation:
   http://localhost:8000/docs

TESTING:

1. Health check:
   curl http://localhost:8000/health

2. Onboard artisan:
   curl -X POST http://localhost:8000/api/artisan/onboard \
     -H "Content-Type: application/json" \
     -d '{"name":"Priya","craft_type":"pottery","location":"Jaipur","experience_years":8,...}'

3. View workflows:
   curl http://localhost:8000/api/workflows

4. Swagger UI:
   Visit http://localhost:8000/docs for interactive testing
