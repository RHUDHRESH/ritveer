================================================================================
                            HOW IT ALL WORKS
================================================================================

WHEN USER SUBMITS ANALYSIS:

  1. Browser sends GET request to /api/analyze-with-thinking
  2. Flask opens Server-Sent Events (SSE) stream response
  3. Backend loops through 5 thinking phases:

     For each phase:
       a) Generate phase-specific prompt
       b) Send to Ollama AI (localhost:11434)
       c) Parse response into individual thoughts
       d) Stream each thought as JSON event
       e) Include confidence percentage (30-95%)
       f) Close phase and move to next

  4. Browser receives streaming events
  5. JavaScript updates UI for each event:
     - Creates phase card
     - Adds thought items with animation
     - Updates progress bars
     - Shows confidence badges

  6. After all phases complete:
     - Fetch actual analysis from /api/analyze-artisan
     - Display final results

THE 5 THINKING PHASES:

  1. UNDERSTANDING (3-5 seconds)
     "What is the core problem? List 3 key insights"
     - Identifies artisan type
     - Recognizes specialization
     - Assesses experience level

  2. RESEARCH & CONTEXT (3-5 seconds)
     "What relevant market context applies?"
     - Market analysis
     - Industry trends
     - Competitive landscape

  3. ANALYSIS (3-5 seconds)
     "What constraints and opportunities exist?"
     - Production capacity
     - Pricing strategy
     - Differentiation factors

  4. SYNTHESIS (3-5 seconds)
     "How do elements work together?"
     - Strategic combinations
     - Multi-channel approach
     - Growth integration

  5. VERIFICATION (3-5 seconds)
     "Does reasoning hold?"
     - Validates conclusions
     - Checks consistency
     - Assesses feasibility

================================================================================
                            TROUBLESHOOTING
================================================================================

Thoughts not appearing?
  1. Check Ollama: curl http://localhost:11434/api/tags
  2. Check Flask: curl http://localhost:5000/api/health
  3. Open console (F12) and look for errors
  4. Check Network tab for /api/analyze-with-thinking

Slow response?
  - This is normal, Ollama is processing
  - Try shorter description
  - Check system resources (CPU, RAM)
  - Each phase takes 3-5 seconds

Styling broken?
  - Clear cache (Ctrl+Shift+Del)
  - Hard refresh (Ctrl+F5)
  - Try different browser
